# Voiceprint self-check

Run this on your own edit before returning it. Answer each check pass or fail. If anything fails, fix the draft and run the checks again. Do not hand back a draft with an open fail.

For a **detect** request, only the last section applies.

## Voice preserved

1. Would the writer recognize the edited draft as their own — same person, sharper?
2. Are the 3–5 voice signals you named (vocabulary, cadence, bluntness, humor, uncertainty, digressions) still present?
3. Did you leave strong human sentences alone instead of rewriting them for consistency?
4. Is the amount of cutting proportional to the actual slop — no aggressive compression that strips character?
5. If you added voice, was the draft genuinely flat first, and did you avoid overwriting a voice that was already there?

## Meaning intact

6. Does the edit preserve the writer's point and add no new claims, numbers, examples, quotes, or opinions?
7. Where a fact was specific, did you protect the specific fact instead of smoothing it into generic importance?
8. Did you ask rather than guess wherever a sentence was genuinely unclear?

## Tells removed

9. Manufactured contrast, negative stacking, rhetorical bait, throat-clearing, and lone-expert setups — gone?
10. Pseudo-analysis `-ing` clauses, colon drama, hollow strong verbs, synonym rotation, and fragment drama — fixed?
11. Importance puffery and weasel attribution — replaced with plain fact and a named source, or flagged to the writer where no source exists?
12. Profound-kicker and recap endings — cut, so the piece ends on a concrete point, takeaway, or next step (kicker deleted, not rewritten into a better metaphor)?

## Words, format, rhythm

13. Cut-on-sight machine vocabulary, empty adverbs, and filler openers — removed unless quoted as examples?
14. Em dashes sparse (none in short copy, one or two in longer drafts only where they clearly help)? Colons in sentence case unless grammar requires otherwise?
15. Formatting slop gone: no emoji headings, no decorative mid-sentence bold, no bullets that should be prose, no headers over tiny sections?
16. Does the draft avoid machine rhythm — repeated sentence shapes, identical paragraph lengths, stacked fragments, three-item lists everywhere?

## Register and delivery

17. If a specialist register applied (briefing, marketing, proposal, message), did you defer to that skill and remove tells only — without flattening its register?
18. Does the final output include the full edited draft and a short **What changed** note (cut, kept, deferred)?

## Detect requests only

19. Does the response name each tell with its quoted line and a short fix — without rewriting, scoring, or claiming a machine wrote it?
